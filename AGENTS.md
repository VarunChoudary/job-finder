# Project working agreement

After every major Job Finder update, run appropriate checks, scan for secrets, commit and push the reviewed source to VarunChoudary/job-finder, and verify the remote commit before reporting completion. Do not force-push or overwrite unrelated remote changes. Keep API keys, personal resumes, environment files, build output and dependencies out of Git. Preserve the public/private visibility chosen by the owner. Back up work before ending a substantial implementation session.
